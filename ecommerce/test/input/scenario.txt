# all the way through the lifecycle to delivered

# Edge case: cannot cancel a delivered order (State pattern rejects it)
CANCEL O1

# Edge case: checkout fails stock check (Chain of Responsibility, first link)
ADDCART bob KEYBOARD001 100

# Edge case: checkout fails payment authorization (Chain of Responsibility,
# last link) -- stock must be untouched since the chain rejects before
# EcommerceService.checkout() reserves anything

CHECKOUT bob 456_Oak_Ave NONE INVALID_CARD
INVENTORY

# bob retries with a valid card -> succeeds, then cancels while still
# PLACED -> inventory is restocked
CHECKOUT bob 456_Oak_Ave NONE CARD

INVENTORY
