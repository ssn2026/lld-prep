# Chess scenario: setup, illegal-move edge cases, then the fastest possible
# real checkmate (Fool's Mate: 1. f3 e5 2. g4 Qh4#) to exercise CHECK ->
# CHECKMATE state transitions and the GameOverException guard.

STATUS
